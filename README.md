# CSS Fundamentals, Layout & Responsive Design

Repository ini berisi kumpulan latihan, eksperimen, dan studi kasus **CSS**—mulai dari sintaks dasar, *box model*, dan teknik *layout* klasik hingga **Flexbox**, **CSS Grid**, dan **Responsive Design**.

## Struktur Folder

- **`CSS_Dasar_Layout/`**
  - **`CSS Dasar/`** — Materi fondasi CSS: *inline/internal/external CSS*, *selector*, *cascade & inheritance*, warna, teks, *box model* (`margin`, `padding`, `border`, *width/height/overflow*), *display*, *list*, *table*, form, gambar, *study case*, serta folder `LatihanCSS`, `Project`, `Style`, `TXT`, dan `CSS_Ridho`.
  - **`CSS Layout/`** — Latihan pengaturan posisi dan tata letak (`relative`, `absolute`, `fixed`, `sticky`, `z-index`, `float`, multi-kolom, *fixed-width*, *liquid*, *grid*, *responsive layout*, hingga *mobile responsive layout*), ditambah folder `Tambahan`, `Latihan` (`CSS01`–`CSS06`), dan `Project`.
- **`CSS_Flexbox_Grid_ResponsDesig/`** — Latihan dan praktik tata letak modern menggunakan **Flexbox**, **CSS Grid**, serta pendekatan **Responsive Design**.
- **`Tulisan.txt`** — Catatan ringkas tambahan.

## Ringkasan Topik

| Tahap | Materi Utama |
| :--- | :--- |
| **CSS Dasar** | Cara penulisan CSS, *selector*, *cascade & inheritance*, warna & teks, *box model*, *display*, *list*, *table*, form, dan gambar |
| **Layout & Positioning** | `position` (`relative`, `absolute`, `fixed`, `sticky`), `z-index`, `float`, multi-kolom, *fixed/liquid layout*, serta latihan bertahap |
| **Flexbox, Grid & Responsive** | Penyusunan layout fleksibel, tata letak berbasis grid, dan adaptasi tampilan untuk berbagai ukuran layar |
